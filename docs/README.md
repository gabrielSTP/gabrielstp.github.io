# 🌟 Gabriel Cardoso Elias - Portfolio Moderno

Um portfólio pessoal visualmente impressionante com design inspirado no estilo "liquid glass" do iPhone. Apresenta projetos, experiência e informações de contato com uma experiência interativa e responsiva.

## ✨ Características

### 🎨 Design Moderno
- **Liquid Glass Glassmorphism**: Efeito de vidro frosted inspirado no design do iPhone
- **Gradientes Fluidos**: Cores vibrantes com transições suaves
- **Animações Sofisticadas**: Efeitos de entrada, hover e interatividade
- **Totalmente Responsivo**: Funciona perfeitamente em todos os dispositivos

### 🌈 Visuais
- Fundo com gradientes dinâmicos
- Cards com efeito de vidro translúcido
- Botões com animações de ripple
- Modals elegantes com backdrop blur
- Scrollbar customizada com gradientes

### 🚀 Funcionalidades
- Navegação suave com scroll automático
- Modals interativos para detalhes de projetos
- Efeitos parallax sutis
- Navegação com indicador de seção ativa
- Animações ao entrar na viewport

## 🚀 Como Usar

1. **Clone ou baixe o repositório**
```bash
git clone https://github.com/gabrielSTP/portfolio.git
```

2. **Abra o arquivo index.html**
```bash
# No Windows
start index.html

# No macOS
open index.html

# No Linux
xdg-open index.html
```

3. **Ou use um servidor local**
```bash
python -m http.server 8000
# Acesse http://localhost:8000
```

## 📝 Personalizações

### Mudar cores
Edite as variáveis CSS em `css/style.css`:
```css
:root {
    --primary-color: #00a8ff;
    --secondary-color: #6366f1;
    --accent-color: #ec4899;
    /* ... */
}
```

### Adicionar novos projetos
Duplique a estrutura `.project` no HTML e ajuste o conteúdo.

### Modificar animações
Ajuste os valores em `@keyframes` no CSS.
